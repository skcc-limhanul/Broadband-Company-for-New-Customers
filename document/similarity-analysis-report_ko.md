# 일일 가입자 유사도 — 독립 리프 세그먼트 분석

## 정정된 분석 기준

**하나의 시계열은 하나의 `(service, service_sub, channel)` 조합입니다. 서로 다른 조합의 수치는 절대 합산하지 않습니다.** 대상 윈도우는 자체 세그먼트의 과거 윈도우만 검색합니다. 이 보고서는 선택 구성과 지표가 의도한 질문에 답하지 못했던 이전 전체 가입자 분석을 대체합니다.

**20개 세그먼트**를 모두 독립적으로 다시 실행했습니다. 세그먼트당 700개(그중 CNN 설정 40개)를 포함한 **주 그리드 세그먼트/구성 시험 14,000회**와 세그먼트당 6개인 **요일 인지 DTW 정제 120회**입니다. 따라서 정정된 실행은 **주 그리드 신경망 설정 800개**를 포함해 **14,120회**를 실행했습니다. 각 세그먼트에는 자체 튜닝 승자, 모델 적합, 후보 풀 및 정규화가 있습니다. 상속된 집계 승자나 세그먼트 간 매칭은 없습니다.

## 데이터 감사 및 준비

기존 `subscribers_historical` 테이블에는 8,280개 레코드가 있습니다. 20개 독립 세그먼트 × 연속 날짜 414개(2026-01-01~2027-02-18)입니다. 각 세그먼트/날짜에는 정확히 하나의 수치가 있습니다. 어떤 세그먼트에도 누락된 날짜나 수치, 중복 세그먼트/날짜 키가 없으며 수치는 양수입니다. 원본은 읽기만 했고 생성하거나 수정하지 않았습니다.

저장소의 가져오기 스크립트는 통합 문서의 `개통자수_일별` 시트를 이 테이블에 매핑합니다. 원본 통합 문서의 생성 방식/출처는 검증되지 않았습니다. 작업 날짜인 2026-09-14 이후 날짜는 검증된 미래 관측값이 아니라 데이터셋 레이블로 취급합니다.

## 평가 프로토콜

주 그리드는 30, 45, 60, 75, 90일 윈도우와 11가지 변환을 사용합니다. z-점수, 최소-최대, 상대 평균, 상대 첫 값, 중앙 3/7/14일 평활화 후 z-점수, 추세 제거 z-점수, 1차 차분 z-점수, 변화율 z-점수, 로그 z-점수입니다.

방법은 RMS 유클리드, 코사인, 상관관계, 5/15/30% 밴드 DTW(최소 반경 2), 표준화 통계 특성 거리, 순위 가중 DTW/상관관계/유클리드 하이브리드 3종, CNN 아키텍처/시드 조합 4종 및 최근/요일-최근 기준선입니다. CNN은 z-점수 및 상대 평균 입력으로 시험합니다. 기준선/전처리 조합은 동일한 기준선 동작을 반복하므로 세그먼트당 명목 구성 700개가 700개의 독립 아이디어는 아닙니다.

- Tuning query ends: 2026-09-12, 2026-09-26, 2026-10-10, 2026-10-24, 2026-11-07, 2026-11-21, 2026-12-05.
- Holdout query ends: 2026-12-19, 2027-01-02, 2027-01-16, 2027-01-30.
- All lengths and segments use these same seven tuning and four holdout endpoints.
- The winner for each segment minimizes its own tuning seven-day top-three continuation RMSE, excluding baseline rows. Holdout scores do not select it.
- Fourteen-day continuations are also scored. Query endpoints are fourteen days apart; target windows still overlap, so results are dependent.
- Candidates end at least `max(14, window_length // 2)` index-days before the target starts. Candidate continuations therefore also precede the target.
- Retrieved starting dates are at least seven days apart. Candidates can still share many observed days; they are not independent historical events.
- Across all 308,000 query/horizon rows, 4,126 rows return fewer than five diversified neighbors. All rows have at least three, so the selection criterion always uses three neighbors. Top-five errors average available neighbors.
- CNN fitting, feature scaling and rank normalization use only eligible older windows **within that segment**. No other segment's records enter these operations.

다음 주 수치는 자체 직전 관측 윈도우의 평균으로 나눕니다. 이 평균은 한 세그먼트 내의 날짜만 평균 내며 세그먼트 키를 결합하지 않습니다. 평균 100 뒤의 수치 110은 1.10이 됩니다. 평가는 이 상대 경로를 비교합니다. RMSE는 일일 제곱 오류 평균의 제곱근이며 낮을수록 좋습니다. 가입자 수 기준 오류나 백분율 정확도가 아닙니다.

| 보고서 열 | 정의 |
| --- | --- |
| `top3_rmse_tune` | Average the three individual neighbor continuation RMSEs per tuning query, then average the seven query scores |
| `top3_rmse_holdout` | Same calculation over the four holdout queries |
| `ensemble3_rmse_holdout` | Average three normalized continuation paths first, calculate that combined path's RMSE, then average over holdout queries |
| `shape_corr_holdout` | Average raw-window Pearson correlation between each holdout target and its rank-1 candidate; observed shape only, not future error |

앞의 세 열은 낮아야 합니다. 형태 상관관계는 +1에 가까워야 합니다. 형태 상관관계가 높아도 미래 연속성 정확도는 낮을 수 있습니다. 초보자용 예시는 [간단한 보고서](similarity-analysis-report-simple_ko.md)를 참조하세요.

### 거리 및 특성 정의

유클리드 거리는 변환된 윈도우의 지점별 RMS 거리입니다. 코사인 거리는 1에서 벡터 코사인을 뺀 값이고, 상관 거리도 1에서 피어슨 상관관계를 뺀 값입니다. 중심화·표준화된 데이터에서 이 방법들은 같은 순위를 낼 수 있으므로, 표시된 승자가 동률 대안보다 유일하게 뛰어난 것은 아닐 수 있습니다.

DTW는 지정된 밴드 안에서 누적 비용이 최소인 경로를 따라 국소 절대 차이를 합산한 뒤, 선택된 경로의 길이로 나눕니다. 평균 경로 비용을 직접 최적화하지는 않습니다. 통계 특성은 평균, 표준편차, 1/3사분위수, 선형 기울기, 평균 절대 1차 차분, 1차 차분 표준편차, 반 윈도우 평균 대비, 7시차 상관 거리입니다. 특성 스케일링은 같은 세그먼트의 적격 과거 윈도우에 맞춥니다.

`(DTW 15%, 상관관계, 유클리드)`의 하이브리드 가중치는 `hybrid`에서 `(0.45, 0.35, 0.20)`, `hybrid_shape`에서 `(0.20, 0.60, 0.20)`, `hybrid_warp`에서 `(0.70, 0.20, 0.10)`입니다. 각 구성 요소는 동률 평균 백분위 순위를 사용합니다. 하이브리드 거리 0은 후보가 구성 요소 순위에서 선두임을 뜻할 뿐, 두 관측 시퀀스가 동일함을 뜻하지 않습니다. 최근 기준선은 적격 최신성을 순위화하며, 요일 버전은 시작 요일이 일치하는 경우를 우선합니다.

CNN 쌍 뷰는 표준편차 0.02의 독립 가우스 잡음을 사용하며 두 분기는 인코더 가중치를 공유합니다. 모든 변환과 학습 파라미터는 하나의 세그먼트 내에 유지됩니다. 이동 평균은 중앙 정렬되지만 관측 윈도우로 제한되고 가장자리에는 더 짧은 평균을 사용합니다. 추세 제거는 적합 직선을 제거하고, 1차 차분과 변화율은 시퀀스 길이를 하나 줄이며, `log_zscore`는 표준화 전에 `log1p`를 사용합니다.

## 한계 및 재현성

이전 전체 가입자 분석의 권고는 이어받지 않습니다. 관련 근거는 세그먼트별 결과입니다. 데이터셋이 짧고 세그먼트당 홀드아웃 쿼리는 4개뿐이며 후보 윈도우는 겹치고 많은 설정을 시도했습니다. 선택된 모델이나 높은 형태 상관관계 모두 미래 가입자 행동을 보장하지 않습니다. 이후 홀드아웃 쿼리는 앞선 홀드아웃 관측값이 과거가 된 후 사용할 수 있으며, 이는 확장형 시간순 평가입니다.

종합 점수는 관측 윈도우 평균으로 정규화합니다. 이 추출 데이터의 모든 평균은 양수이며, 평균이 0인 시계열에는 별도의 평가 설계가 필요합니다. 중앙 평활화는 각 관측 윈도우 안에 제한됩니다. 누락 관측값은 미래 값으로 채우지 않고 거부합니다. 6개 DTW 정제는 진단용이며 품질과 관계없이 모든 값을 유지합니다.

빠른 스윕은 계속 사용할 수 있지만 이전의 연속성 대리 지표를 사용합니다. 빠른 스윕 오류를 이 보고서의 종합 점수와 혼합하지 마세요.

```bash
PYTHONDONTWRITEBYTECODE=1 MPLBACKEND=Agg OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
  /tmp/broadband-similarity-env/bin/python process/similarity/similarity_check.py \
  --comprehensive --workers 6 --output-dir /tmp/broadband-leaf-analysis
```

선택적 의존성은 이전 실행에 사용한 외부 환경에 설치했습니다. 버전: {"python": "3.12.12", "numpy": "2.5.1", "pandas": "3.0.5", "torch": "2.14.0"}. Every segment's data SHA-256, full key, dates and selected configuration are recorded in `segment_manifest.json`.

모든 수치 출력은 `/tmp/broadband-leaf-analysis/`에 있으며 세그먼트마다 별도의 안정 ID 디렉터리가 있습니다. 주 요약 행은 56,000개, 쿼리/예측 기간 행은 308,000개, 전체 구성 최신 매칭은 70,000개, 선택된 최신 매칭은 100개입니다. 모든 CSV에는 세 차원 키가 모두 포함됩니다. 로컬 CSV/JSON은 저장소 밖에 두며, 보고서 이미지와 [전체 14,000행 구성 부록](similarity-analysis-segment-configurations.md)은 의도적으로 제공하는 문서 산출물입니다.

회귀 검증은 결합 세그먼트 거부, 다른 채널 변경에 대한 불변성, 부분 필터 디스패치, 누락/중복 관측값, DTW, 동률 순위, 상수 변환 및 미래 격리 CNN 학습을 포괄합니다. 전체 실행 및 결과 감사는 20개 세그먼트 ID, 동일 세그먼트 수치, 후보 날짜 간격, 튜닝 전용 선택, 결과 차원 및 유한 지표를 검증합니다. 작업 요약은 `document/job/job.log`를 참조하세요.
