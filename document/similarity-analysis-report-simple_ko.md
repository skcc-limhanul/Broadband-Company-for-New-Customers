# 일일 가입자 유사도 — 초보자 가이드

## 정정 사항: 한 번에 하나의 세그먼트

**하나의 `(service, service_sub, channel)` 조합에 대한 일일 가입자 수를 비교합니다. 전체 가입자 수는 사용하지 않습니다.**

예를 들어 `초고속 / IP / 직접`은 하나의 시계열이고, `초고속 / IP / SKT`는 다른 시계열입니다. 첫 번째 시계열의 대상은 해당 시계열의 이전 날짜만 탐색합니다. 두 번째 시계열은 가입자 수, 모델 학습 데이터 또는 과거 후보에 기여하지 않습니다.

이전 보고서는 합계를 사용했으므로 잘못된 질문에 답했습니다. 기존의 전체 45일 상관관계 권고는 대체되었습니다. 정정된 실행에서는 **20개 세그먼트를 모두 독립적으로** 분석했으며, **세그먼트당 주 설정 700개와 DTW 후속 설정 6개, 총 14,120회**를 시험했습니다. 각 세그먼트는 자체 선택 방법을 갖습니다.

분석 레코드를 임의로 만들지 않았습니다. 기존 데이터베이스에서 가져온 것이며, 저장소의 가져오기 스크립트는 제공된 통합 문서의 `개통자수_일별` 시트를 가리킵니다. 원본 통합 문서가 시뮬레이션 데이터인지 여부는 확인되지 않았습니다. 2027-02-18까지의 날짜는 검증된 미래 관측값이 아니라 데이터셋 레이블입니다.

다음 수치는 **설명 목적으로만 만든 것이며 실행에 사용되지 않았습니다**. 두 열은 *동일한* 세그먼트의 서로 다른 과거 기간이라고 생각하면 됩니다.

| 윈도우 내 일자 | 대상 기간 | 과거 기간 |
| --- | ---: | ---: |
| 1 | 100 | 200 |
| 2 | 120 | 240 |
| 3 | 80 | 160 |

한쪽의 가입자 수가 두 배이더라도 두 기간은 함께 상승하고 하락한 뒤 회복합니다. 정규화는 규모만이 아니라 이러한 형태를 비교하도록 돕습니다.

## 방법은 어떻게 선택하나요?

30~90일 윈도우, 수치를 평활화/정규화하는 방법 및 여러 매칭 방법을 시험합니다. 이전의 **튜닝 날짜** 7개에서 가장 가까운 과거 윈도우 3개를 찾고, 그 다음 주가 대상의 다음 주와 얼마나 유사한지 확인합니다. 평균 오류가 가장 낮은 설정을 **세그먼트별로 독립적으로** 선택합니다.

그 후 해당 설정을 선택에 사용하지 않은 이후의 **홀드아웃 날짜** 4개에서 확인합니다. 모든 후보는 같은 세그먼트의 이전 윈도우입니다. 후보끼리는 겹칠 수 있지만 대상과는 겹칠 수 없습니다. 이는 유용한 과거 기반 테스트일 뿐 예측 정확도의 증명은 아닙니다.

## 네 가지 지표를 쉽게 설명하면

**RMSE**는 오류를 측정합니다. 각 날짜 차이를 제곱하고 다음 7일 동안 그 제곱의 평균을 낸 뒤 제곱근을 구합니다. 낮을수록 좋으며, 0은 완벽한 일치를 뜻합니다.

먼저 다음 주의 각 수치를 바로 앞 관측 윈도우의 평균으로 나눕니다. 이 평균에는 같은 세그먼트의 날짜만 사용합니다. 예를 들어 평균이 100인 윈도우 뒤의 110은 `1.10`이 됩니다. 따라서 오류는 가입자 수나 백분율 정확도가 아닌 상대 척도를 사용합니다.

| 지표 | 의미 | 개선 방향 |
| --- | --- | --- |
| `top3_rmse_tune` | 세 매칭의 다음 주를 각각 평가해 세 오류의 평균을 구한 뒤, 7개 튜닝 날짜에 대해 다시 평균을 냅니다. 세그먼트 방법 선택에 사용합니다. | 낮을수록 좋음 |
| `top3_rmse_holdout` | 이후 홀드아웃 날짜 4개에서 같은 방식으로 계산합니다. 선택된 방법의 일반화 정도를 보여 줍니다. | 낮을수록 좋음 |
| `ensemble3_rmse_holdout` | 먼저 정규화된 다음 주 경로 3개를 날짜별로 평균 낸 뒤, 결합 경로를 평가하고 홀드아웃 날짜에 대해 평균을 냅니다. | 낮을수록 좋음 |
| `shape_corr_holdout` | 각 홀드아웃 대상의 관측 일일 패턴을 원시 윈도우 상관관계로 최상위 과거 매칭 하나와 비교하고, 홀드아웃 날짜에 대해 평균을 냅니다. 미래 정확도는 측정하지 않습니다. | +1에 가까울수록 좋음 |

상관관계 +1은 상승과 하락이 완벽히 일치함을, 0은 선형 관계가 없음을, −1은 반대 방향으로 움직임을 뜻합니다. 상관관계가 높아도 수치가 같거나 다음 주가 유사하다는 보장은 없습니다.

### “상위 3개”와 “앙상블”: 가상의 하루 예시

실제 정규화 값이 `1.00`이라고 가정합니다. 세 과거 경로의 값은 `0.90`, `1.00`, `1.10`입니다.

- **상위 3개 오류:** 각각 평가한 뒤 평균을 냅니다. `(0.10 + 0.00 + 0.10) / 3 = 0.0667`
- **앙상블 오류:** 먼저 값을 평균 냅니다. `(0.90 + 1.00 + 1.10) / 3 = 1.00`이며 결합 오류는 `0.00`입니다.

이 예시에서는 낮은 추정치와 높은 추정치가 상쇄됩니다. 실제 평가는 7일을 사용한 뒤 쿼리 점수를 평균 냅니다. RMSE 0.08은 “정확도 92%”를 의미하지 않습니다.

## 무엇을 결론 내릴 수 있나요?

관심 있는 **정확한 서비스, 하위 서비스 및 채널**에 해당하는 결과를 사용하세요. 검증 없이 이전 전체 가입자 수 기준 승자나 다른 세그먼트의 승자를 적용하지 마세요.

선택된 모든 세그먼트는 홀드아웃 오류가 튜닝 오류보다 높으므로, 방법이 이후 날짜에서 더 나쁘게 수행되었음을 뜻합니다. 관측된 형태 유사도가 좋아도 다음 주 매칭이 좋다는 보장은 없습니다. 세그먼트당 홀드아웃 날짜가 4개뿐이고 많은 설정을 시도했으므로 결과는 잠정적입니다.

이 추출 데이터에서 최신 대상에는 관측된 다음 주가 없습니다. 미래 정확도는 알 수 없습니다. [정정된 전체 보고서](similarity-analysis-report_ko.md)에는 모든 세그먼트의 매칭과 상세 비교가 담겨 있습니다.
